I Get Bored

aku awal nya cuma iseng,dengan berfikir,cara bikin website sendiri gimana ya,awalnya mikirin orang klo bikin game kok lama ya ngapan sih,trs malah kepikirian bikin website,biar bisa ngerasain,rasanya jadi pengembang suatu aplikasi atau web

Akhir nya saya belajar mulai dari nol,dengan otodidak,saya belajar dengan menontong seorang progamer yg channlenya bernama "Dea Afrizal" nama nya masih ku ingat sampai sekarang,hanya dengan menonton sambil mendengarkan aku akhir nya bisa membuat sebuah web html,beserta code CSS untuk mempercantiknya,awalnya tidak mngerti,hanya mengkuti.

Awalnya bingung gimana cara telepoannya,gimana cara bikin akun,ginmana cara invite temen,wah pokoknya pada bingung dah,semantara itu kam masih bermain sambil berkomunikasi dengan wa,kk nya hampir setiap hari menertawakan nya,karena aneh

Lama lama aku sudah mulai sedikit mengerti,sudah bisa membuat website seperti ini,sendiri,tapi aku sesekali mencari bantuan ke ai hanya karena lupa,manusia itu butuh waktu
